# TagOut

NFC-powered app blocker for Android.  
Tap a tag to lock distracting apps. Tap again to unlock.  
Free alternative to The Brick — no hardware, no subscription.

## How it works
1. Add your NFC tags and name them
2. Build a blocking profile — choose which apps to block
3. Assign lock and unlock tags to the profile
4. Tap from anywhere on your phone — no need to open the app

## Install
Download the APK from [Releases](https://github.com/Diamondlight8/tagout/releases)  
Enable "Install from unknown sources" in Android settings and install.
